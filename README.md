**Installation guide:**
    - install python3.14 or later
    - run `python3 -m venv your_environment_name`
    - run `source your_environment_name/bin/activate`
    - run `your_environment_name/bin/pip install -f requirements.txt`
    - After it finishes run `your_environment_name/bin/python3 app.py` and you are good to go
